# 2D FEniCS simulation

This folder contains a  version of the Python/FEniCS code used to simulate the 2D reduced clonal-growth model for *Posidonia oceanica*.

The code is intentionally focused on the procedure actually used in the manuscript simulations:

- nondimensionalisation from the selected dimensional parameter set;
- square 2D computational domain;
- two Gaussian initial vegetation patches;
- mixed finite-element formulation for the shoot density and its Laplacian;
- fixed time-step integration;
- XDMF output for visualization and post-processing.



## Main file

```text
fenics_code.py
```

## Requirements

The script requires a working FEniCS installation with `dolfin` and `mshr`.

A typical execution environment is the legacy FEniCS 2019 Docker image or an equivalent local installation.

## Run

```bash
python fenics_code.py
```

Optional arguments:

```bash
python posidonia_2d_fenics_clean.py \
  --output-dir data \
  --mesh-resolution 80 \
  --final-time 1000 \
  --dt 0.5 \
  --save-every 1.0 \
  --domain-length 1250
```

The time, time step, save interval, and domain length are given in the dimensional units used before nondimensionalisation. The script converts them internally.

## Output

The default output folder is:

```text
data/
```

The script writes (along with the .h5 related files):

```text
domain.xdmf
density.xdmf
laplacian_density.xdmf
density_LAST.xdmf
laplacian_density_LAST.xdmf
parameters.txt
time_log.txt
mortality_log.txt
```

The `.xdmf` files can be opened in ParaView or in Matlab

## MATLAB visualization

The simulation saves the density field in XDMF/HDF5 format.  
The main file to read in MATLAB is:

```text
data/density.h5
```

A minimal MATLAB script to load and plot one saved field is:


clear; close all; clc;

% HDF5 file generated by FEniCS
fileh5 = 'data.h5';
domain= 'domain.h5';
% If needed, inspect the internal structure with:
% h5disp(fileh5)

% Read mesh
coordinates = h5read(domain, '/Mesh/mesh/geometry');
triangles    = h5read(domain, '/Mesh/mesh/topology');

% MATLAB sometimes reads the arrays transposed
coordinates = coordinates';
triangles    = triangles';

% FEniCS uses zero-based indexing, MATLAB uses one-based indexing
triangles = triangles + 1;

% Choose which saved time step to plot
% Usually: 0 = initial condition, 1 = first saved step, etc.
step = 10;

% Read density field
dataset = ['/VisualisationVector/' num2str(step)];
u = h5read(fileh5, dataset);
u = double(u(:));

% Coordinates
x = coordinates(:,1);
y = coordinates(:,2);

% Plot
figure;
trisurf(triangles, x, y, u);
```
